《家园：卡拉克沙漠》的非官方《明日方舟》／《明日方舟：终末地》同人 Mod，将罗德岛作为玩家阵营接入遭遇战。

**[下载完整安装包：GitHub Releases](https://github.com/PFMartist/Arknights-Deserts-of-Talos-II/releases)**

> 本mod只在github发布，且完全免费，如果您是通过付费渠道获取，请注意维权。

当前版本为 **Beta v0.1**，实现基于 Hotfix65，启动器版本为 **62.4**。完整玩家包请从 Releases 页面下载。

- 罗德岛母舰，可选择航空或炮战改装，两条路线互斥。
- 配套地面载具、轻型自行火炮、拦截机、重型轰炸机和干员运输旋翼机。

## 安装与启动

需要 Windows 64 位环境及通过 Steam 安装的《家园：卡拉克沙漠》。当前支持目标为 Steam build **12339551**；安装器会核对游戏目录和核心文件版本。完整包不包含游戏本体。

1. 从 Releases 下载完整玩家包，全部解压到固定目录。保留 `payload`、`release.json` 和启动器等文件。
2. 正常退出游戏，保持 Steam 登录，双击 **`RhodesMod.exe`**。需要时用菜单 **6** 选择真实 Steam 库中的 `Deserts of Kharak` 游戏目录。
3. 选择 **1「安装 Mod」**，等待安装成功提示。
4. 选择 **2「启动 Mod」**，经 Steam 进入游戏主菜单。
5. 进入遭遇战，将自己的阵营设为罗德岛，给电脑对手选择原版阵营，然后开始游戏。

启动器和 Steam 按普通用户权限运行。安装或启动遇到问题时，可先用菜单 **7** 检查启动条件，菜单 **3** 校验安装文件。包内也保留了 `RhodesMod.cmd`、`InstallMod.cmd` 等入口。

Releases 中的完整玩家包包含安装器和资源。仓库的 **Code → Download ZIP** 是源码，用于开发，不能直接安装游玩。

## 更新、修复与卸载

**跨版本更新：**先退出游戏，用当前已安装版本的旧启动器选择 **5「卸载 Mod」**，再用完整解压的新包选择 **1「安装 Mod」**。保留旧包直到卸载完成。

**同版修复：**备份自己改过的文件后，用对应版本启动器选择 **4「修复 Mod 文件」**。修复按本版清单恢复受管文件。

**卸载：**用已安装版本的启动器选择 **5**。它会核对安装记录，只移除该版本管理的文件，保留游戏本体、存档和设置。文件被手动修改时可能停止，请先保存改动，再用匹配版本修复、卸载。

## 已知限制与反馈

- 数值尚未完成系统平衡，干员操作和部分技能表现仍可能需要调整。
- 长局和大量单位场景仍可能卡顿。车辆、舰载机及母舰已加入渲染优化，但不同硬件、地图和镜头下的收益需要继续观察。
- Hotfix65 修复跨局机库与干员管理界面的绑定和重建逻辑，已通过离线回归。同一游戏进程内连续两局的实际界面和操作仍待验证。
- 联机 PvP/PvE、电脑操控罗德岛，以及全部地图与 DLC 组合尚未完成验收。建议按上面的单机遭遇战范围游玩。

如需记录问题，可提交 [Issue](https://github.com/PFMartist/Arknights-Deserts-of-Talos-II/issues)。请附上启动器显示的版本、地图、双方阵营、操作步骤和复现方式。游戏日志位于游戏目录的 `BepInEx/MapUnitLab.Runtime.log` 与 `Data/output_log.txt`；分享前请检查其中的个人信息。更详细的限制见随包 `KNOWN_ISSUES.md`。
